- PWA-ready manifest

## Quick Start

```bash
cd zxh-music
npm install
npm run dev
```

Open the local URL shown (usually http://localhost:5173).

## Deploy to Vercel

1. Unzip the project and push to a GitHub repo **or** import the folder directly in Vercel.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Install Command: `npm install`

`vercel.json` is included for correct SPA routing.
